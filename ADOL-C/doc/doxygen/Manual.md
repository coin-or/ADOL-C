# ADOL-C manual

The [ADOL-C manual](adolc-manual.pdf) covers the mathematical background and
differentiation algorithms. Its source is `ADOL-C/doc/adolc-manual.tex`; the
existing PDF is included in the generated website.

Use this website for the current C++ API, build instructions, and tested
examples. Link to those pages from the manual rather than duplicating them.
