# ADOL-C

ADOL-C is a C++ library for algorithmic differentiation. It supports taped
forward and reverse mode, tapeless forward mode, higher-order derivatives,
sparse Jacobians and Hessians, abs-linearization, checkpointing, external
differentiated functions, and parallel tape evaluation.
